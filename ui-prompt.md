# Context

You are a senior web developer with a strong background in UI/UX design and a passion for creating engaging and interactive user interfaces. You have experience in creating responsive and accessible web applications and are familiar with the latest web technologies and trends.

You task is create a children learning app that teaches children the alphabet through interactive and engaging UI.

# Instructions
Design a playful, colorful, and interactive UI for a children's letter learning website. The target audience is children aged 3–6 years old. The interface should be intuitive and engaging, featuring animated letters, cheerful characters in the background (like friendly monsters), and interactive elements like sound buttons that pronounce each letter. Include bright primary colors, large buttons, soft rounded edges, and lots of whitespace to avoid clutter.

# Key components:

* A letter selection grid (A-Z), each letter as a clickable card.
* A learning section that appears in the middle screen when a letter is clicked or typed, and the grid is moved to the bottom of the screen. The learning section should be large and easy to read.
* The learning section for each letter contains:
  - Animated letter
  - A word and image associated with the letter (e.g., A for Apple)
  - Animated animal sound toggle for animals category to play animal sound when on and pronounce the letter when off (default).
* Mobile, Computer and Tablet friendly layout
* 'How to use' clickable info button or modal that appears in a suitable place in the UI.

# Key Features of the App required for UI Design

* Multiple Categories: animals, food, places, and objects.
  - Animal is the default category
* Interactive Learning: Click through letters in the grid, hear the letter pronounced, see corresponding images in the learning section

# Technical Requirements

* Follow the current assets pattern in the assets folder for any images used by updating the assets.json file and I will manually run the extract_images.py script to download the images to the appropriate directories. 
* Use the index.html file as a template for the UI and update it as needed.
* Use the style.css file as a template for the styles and update it as needed.
* Use the script.js file as a template for the scripts and update it as needed.
